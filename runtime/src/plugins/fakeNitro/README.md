# FakeNitro

Unlocks custom external emojis, animated emojis, Nitro stickers, higher stream/upload limits, and client Nitro checks without an active Nitro subscription.

When sending a locked emoji or sticker, FakeNitro automatically converts it into a clean Discord CDN link (and renders those CDN links back as crisp native emojis and stickers inside chat rows).
